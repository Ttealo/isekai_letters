# 이세계 우체통 (isekai_mailbox)

Lumiverse 확장(Spindle)입니다. 다른 세계에 사는 누군가와 **편지만** 주고받습니다.

- 보낸 편지는 실제 시간으로 배송되고(몇 시간 ~ 하루), 상대 세계의 시간은 다른 빠르기로 흐릅니다.
- 답장은 그사이 상대에게 생긴 일과 감각(냄새·감촉·날씨)을 품고 돌아옵니다.
- 상대·세계·편지 재질은 AI가 함께 만들고, 편지가 쌓일수록 기억·관계·로어북이 정리됩니다.
- 봉투·상징물·추억 상자·초상화를 그림으로 그리거나, 그림 없이 글로 묘사할 수 있습니다.

## 주요 기능

**편지 상대 만들기**
- 원하는 상대를 글로 적기, 무작위로 만나기(세계·키워드·종족·성별·나이·직업 예시를 주사위로 굴려 참고), 기존 캐릭터와 편지하기, 직접 다 적기
- 확정하면 캐릭터 카드와 그 세계의 로어북(세계 개요·달력과 시간·우편 수단 등)이 함께 생깁니다.
- 상대가 먼저 편지를 쓰게 하면 첫 편지가 바로 도착해 있습니다.
- 페르소나를 골라 편지를 쓰거나, 「페르소나 없음」으로 현실의 나 자신으로 쓸 수 있습니다.

**시간과 배송**
- 상대마다 시간 비율(내 하루 = 그쪽 며칠), 배송 시간, 답장 쓰는 시간, 그쪽 달력(하루 길이·달 이름)
- 가끔 우체부가 늦습니다. 오래 답이 없으면 상대가 먼저 편지를 쓰기도 합니다.
- 편지가 도착하면 푸시 알림(루미버스 알림 등록 필요)

**편지첩**
- 왼쪽: 페르소나 → 나 → 편지 상대
- 상대를 고르면: 편지첩 / 물건 / 추억 상자 / 기록부
- 「나」를 고르면: 내 모습 / 추억 상자(모든 상대) / 달력(주고받은 날)
- 편지지는 상대마다 테마(글씨체·종이 결·가장자리·무늬·색)로 꾸며지고, 사건이 생기면 그 편지부터 바뀝니다.
- 안 읽은 편지는 봉투로, 열면 편지지로. 동봉물·사진은 편지 아래 썸네일(누르면 크게)
- 내 편지에 사진을 넣거나, 글로 적은 장면을 그림으로 그려 넣을 수 있습니다.
- 받은 편지의 글자가 깨졌으면 직접 고칠 수 있습니다(원문 보관).

**기억과 정리**
- 답장이 오면 한 번 더 정리: 편지 요약, 관계 장부(부르는 말·약속·질문·서로 아는 것), 그쪽 연대기, 시기 요약
- 로어북·캐릭터 카드에 바뀐 점을 제안·적용(칸 잠금, 승인 후 적용, 되돌리기)
- 기억을 프롬프트에 넣는 양을 층마다 정할 수 있습니다.
- 「우리의 편지」 로어북 항목: 같은 캐릭터와 일반 채팅을 할 때도 편지로 쌓은 관계를 알게 합니다.

**기록부**
- 원할 때 받는 상대에 대한 기록(문체 선택), 알려진 것, 그쪽 세계 사람들이 하는 말(일부는 가려진 소문), 편지로 이어진 일들의 타임라인. 갱신하면 지난 기록이 쌓입니다.

**그림(선택)**
- 봉투·상징물·추억 상자·받은 물건: 이미지 연결(NanoGPT 등)로 그림. 종류마다 연결·모델·양식을 고를 수 있습니다.
- 초상화(상대와 나): NovelAI 연결로, 캐릭터 카드를 NovelAI 태그 프롬프트로 바꿔 그립니다. 화풍·네거티브 프롬프트는 설정에서.
- 「그림 사용 안 함」을 고르면 그리기 없이 모습을 글로 받습니다.
- 그린 그림은 브라우저에서 WebP로 줄여 다시 저장합니다. 하루 최대 장수·상대별 장수를 정할 수 있습니다.

**저장·내보내기**
- 편지첩을 한 장짜리 HTML(표지·편지·기록부·나·모음·타임라인)로 저장
- 백업 파일 받기·되살리기(설정·상대·캐릭터 카드·로어북 사본)

## 필요한 것

- Lumiverse(Spindle 확장 지원 버전)
- 글 생성 연결 1개 이상(답장·정리·상대 만들기). 연결이 한도에 걸리면 고른 대체 연결로 넘길 수 있습니다.
- 그림을 쓰려면: 이미지 생성 연결(NanoGPT 등), 초상화는 NovelAI 이미지 연결

## 설치

루미버스의 확장 관리에서 이 저장소 주소로 설치하고, 아래 권한을 승인합니다.

| 권한 | 쓰는 곳 |
|---|---|
| `generation` | 답장·정리·상대 만들기 글 생성, 연결 목록 |
| `personas` | 페르소나 목록·이름·설명 |
| `characters` | 매칭으로 캐릭터 만들기·읽기, 초상화를 아바타로 |
| `world_books` | 상대 로어북 만들기·읽기·고치기 |
| `image_gen` | 그림 만들기, 이미지 연결·모델 목록 |
| `images` | WebP로 바꾼 그림 올리기, 지운 상대의 그림 지우기 |
| `ui_panels` | 우체통 위젯과 편지첩 창 |
| `app_manipulation` | 편지첩을 화면 가득 열기(없으면 오른쪽에 붙이기) |
| `push_notification` | 편지 도착 알림 |

권한이 없으면 해당 기능만 빠지고 나머지는 동작합니다.

## 처음 쓰기

1. 서랍의 **「우체통」** 탭 → **설정**에서 글 연결(답장·상대 만들기·정리)을 고릅니다. 그림을 쓰려면 「그림」 탭에서 이미지 연결을, 초상화를 쓰려면 「초상화」 탭에서 NovelAI 연결을 고릅니다.
2. **「새 상대」** → 방식을 고르고 만들기 → 미리보기에서 고친 뒤 확정합니다.
3. 화면의 우체통 위젯을 누르면 편지첩이 열립니다. 편지를 쓰면 실제 시간으로 배송되고, 답장은 상대 쪽 시간이 흐른 만큼 늦게 옵니다.
4. 추억 상자 탭의 「모습」 카드에서 초상화·상징물·봉투·추억 상자를 그리거나(그림 사용 안 함이면 글로 받기), 서랍의 서류함에서 편지지 테마·달력·기억을 다듬을 수 있습니다.

## 비용과 속도

- 답장 1통 = 글 생성 1회(+ 정리를 켜면 1회 더). 상대 만들기·기록부·편지지 테마·모습 글은 누를 때마다 1회.
- 그림 1장 = 그림 주제 글 1회 + 이미지 1장. 초상화는 글 1회 + NovelAI 1장.
- 연결이 한도(429)에 걸리면 몇 번 다시 시도한 뒤 대체 연결로 넘어가므로, 처음 한 번은 1분쯤 걸릴 수 있습니다(진행 표시가 뜹니다).

## 데이터

- 편지·기억·설정은 루미버스의 확장 사용자 저장소에 계정별로 저장됩니다.
- 그림은 루미버스 이미지로, 캐릭터·로어북은 루미버스 캐릭터·로어북으로 저장됩니다.
- 상대를 지울 때 그 상대의 그림·캐릭터·로어북을 함께 지울지 고를 수 있습니다.

## 개발

```
node scripts/build.js      # src → dist (이어 붙이기, 의존성 없음)
npm test                   # 단위 + 가짜 호스트 통합 + 빌드 + 가짜 DOM 화면 점검
```

- `src/`: core(시간·편지·설정) · paper(편지지 테마) · match(상대 만들기) · memory(정리·기억) · art(그림 양식) · portrait(NovelAI 프롬프트) · report(기록부·모습 글) · exporthtml(HTML 저장) · backend · frontend
- 가짜 DOM 점검은 `linkedom`이 필요합니다(상위 폴더의 node_modules를 빌려 씀).
- `dist/`는 설치 시 빌드 없이 쓰도록 저장소에 같이 올립니다.
