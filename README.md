# 이세계 편지

> 어느 날, 우체통에 낯선 봉투가 들어 있었어요.

**이세계 편지**는 다른 세계에 사는 누군가와 **편지만** 주고받는 Lumiverse 확장(Spindle)이에요.

- 내가 보낸 편지는 진짜 시간을 들여 건너가요(몇 시간 ~ 하루).
- 그쪽 세계의 시간은 다른 빠르기로 흘러요. 내 하루가 그쪽에선 며칠일 수도 있어요.
- 답장에는 그사이 그 사람에게 있었던 일과 냄새, 날씨, 손끝의 감촉이 함께 담겨 와요.
- 편지가 쌓일수록 약속과 기억, 그 세계의 이야기가 차곡차곡 정리돼요.

---

## 편지 한 통의 여행

1. **보냄** — 편지를 써요. 작은 물건, 사진, 글로 적어 그린 그림을 동봉할 수 있어요.
2. **건너가는 중** — 세계를 건너요(기본 0~6시간). 가끔 우체부가 늦기도 해요.
3. **받음** — 그 사람이 편지를 받고, 답장을 쓰기까지 시간이 흘러요(기본 0~6시간). 그동안 그 사람에게 일이 생겨요.
4. **답장 씀** — 지나간 시간만큼의 일들을 담아 답장을 써요.
5. **건너오는 중** — 답장이 세계를 건너와요(기본 0~6시간).
6. **도착** — 알림과 함께 봉투가 도착해요. 열면 그 사람의 편지지가 펼쳐져요.
7. **기억** — 약속, 묻고 못 들은 말, 그쪽에서 일어난 일들을 정리해 두어요.

한 번 왕복(보내고 → 그쪽이 받고 → 답장이 돌아오기까지)은 최대 48시간 안에서 정해요. 세 구간의 합이 최대를 넘으면 그 안으로 줄여요. 편지첩 아래 띠에 지금 어느 단계인지 보여요.

오래 답장하지 않으면 그쪽이 먼저 편지를 쓰기도 해요. 기다리기 싫은 날엔 **⏩ 바로 받기**로 지금 받을 수 있어요.

## 할 수 있는 것

**상대 만나기**
- 원하는 상대를 글로 적기 · 무작위로 만나기 · 기존 캐릭터와 편지하기 · 직접 다 적기
- 무작위는 세계·키워드·종족(인외 포함)·성별·나이·직업 예시를 주사위로 굴려 영감으로만 삼아요.
- 확정하면 캐릭터 카드와 그 세계의 로어북(세계 개요, 달력과 시간, 우편 수단)이 함께 생겨요.
- 그쪽이 먼저 쓴 첫 편지는 만나자마자 우체통에 들어 있어요.
- 페르소나로 편지를 쓰거나, 「페르소나 없음」으로 이 세계의 나 자신이 될 수 있어요.

**편지첩**
- 왼쪽: 페르소나 → 나 → 편지 상대
- 상대를 고르면: 편지첩 · 물건 · 추억 상자 · 기록부 · 이야기
- 「나」를 고르면: 내 모습 · 내 세계 · 추억 상자(모든 상대) · 달력
- 상대의 편지지는 그 사람다운 글씨체·종이 결·가장자리·무늬·색으로 꾸며지고, 사건이 생기면 그 편지부터 바뀌어요.
- 내 편지의 글씨체도 12가지 중에서 고를 수 있어요.
- 안 읽은 편지는 봉투로, 열면 편지지로. 동봉물과 사진은 편지 아래 썸네일(누르면 크게).
- 지난 편지는 책의 차례처럼 한 줄(보냄/받음 · 첫 줄 · 날짜)로 접혀 있다가 누르면 펼쳐져요. 최근 두 통과 가는 중·안 읽은 편지는 늘 펼쳐 둬요.
- 편지를 쓰는 중에 새 편지 확인이 돌아도 쓰기 칸과 글, 커서가 그대로 남아요.
- 글자가 깨져 온 편지는 직접 고칠 수 있어요(원문 보관).

**기억**
- 답장마다 편지 요약, 관계 장부(부르는 말·약속·질문·서로 아는 것), 그쪽 연대기, 시기 요약을 정리해요.
- 로어북과 캐릭터 카드에 바뀐 점을 제안하고 적용해요(칸 잠금, 승인 후 적용, 되돌리기).
- 「우리의 편지」 로어북 항목으로, 같은 캐릭터와 일반 채팅을 할 때도 편지로 쌓인 사이를 알게 할 수 있어요.

**기록부**
- 원할 때 받는 그 사람에 대한 기록, 알려진 것, 그쪽 세계 사람들이 하는 말(몇은 가려진 소문), 편지로 이어진 일들의 타임라인. 갱신하면 지난 기록 위에 새 기록이 쌓여요.

**내 세계 — 페르소나 쪽도 흘러가요** (페르소나로 쓸 때)
- 페르소나가 사는 세계를 둬요. 페르소나에 붙은 로어북이 있으면 그걸 이어 쓰고, 빠진 것(세계 개요·사는 곳·주변 사람·달력)은 AI가 초안해요. 고친 뒤 확정해요. 새 로어북은 원하면 페르소나에도 붙여요.
- **내 쪽 시계**: 현실과 같이 흐르고, 내 세계의 달력이 있으면 그 달력으로 보여요.
- **내 쪽 연대기**: 시간이 흐르는 동안 내 주변(사람·장소·일)에 있었던 일을 적어요. 자동(답장 정리 때 함께, 글 추가 없음)과 수동(누를 때만) 중에서 골라요. 내 말·감정·선택은 정하지 않아요.
- **시간 감기**: 몇 시간·며칠·몇 주를 감으면, 그 페르소나로 주고받는 모든 상대에게 같은 시간이 흘러요. 가는 편지는 그만큼 도착에 가까워지고, 기다리던 답장은 그만큼 일찍 써져요. 원하면 그사이 내 쪽 일도 받아요.
- 상대는 내 세계를 몰라요. 내가 편지에 쓴 만큼만 알아요. 내 세계는 내 쪽 사건·마무리·HTML 저장에 쓰여요.

**이야기 — 사건과 마무리**
- **사건 일으키기**: 키워드를 적거나 비워 두면 맥락에 어울리는 사건이 생겨요. 그쪽 사건은 그 사람의 삶에 일어나 다음 답장에 스며들고, 내 쪽 사건(페르소나가 있을 때만)은 내 기록에만 남아 상대는 내가 편지에 쓴 만큼만 알아요. 내 쪽 사건은 쓰기 칸 위에도 보여요.
- **마무리하기**: 편지, 상대의 기록과 연대기, 내 페르소나와 내 쪽 사건을 모두 합쳐 그 뒤 어떻게 되었는지 마무리 글을 받아요. 「페르소나 없음」이면 이쪽의 나는 그리지 않고 상대 쪽만 들려줘요. 마무리하면 편지는 멈추고, 「다시 편지 잇기」로 되돌릴 수 있어요.
- **그 후 더 듣기**: 마무리한 뒤에도 궁금한 것을 적으면 그 뒤 이야기를 얼마든지 이어서 들려줘요.

**그림 — 쓰거나, 글로 받거나**
- 봉투·상징물·추억 상자·받은 물건: 이미지 연결(NanoGPT 등)로 그려요. 종류마다 연결·모델·양식을 따로 고를 수 있어요.
- 초상화(상대와 나): NovelAI 연결로, 캐릭터 카드를 NovelAI 태그 프롬프트로 바꿔 그려요.
- 「그림 사용 안 함」이면 그리기 대신 **모습을 글로** 받아요. 문체는 담백하게 · 탐미적으로 · 서정적으로 · 건조한 기록체로 · 직접 적기 중에서 골라요.

**남기기**
- 편지첩을 한 권의 책 같은 HTML(표지·편지·기록부·나·모음·타임라인·그 후)로 저장해요.
- 백업 파일 받기·되살리기(설정·편지·기억과 캐릭터 카드·로어북 사본).
- 헤어질 때는 그 사람의 그림·캐릭터·로어북까지 함께 지울지 하나씩 골라요.

## 필요한 것

- Lumiverse (Spindle 확장 지원 버전)
- 글 생성 연결 1개 이상
- 그림을 쓰려면 이미지 생성 연결(NanoGPT 등), 초상화를 쓰려면 NovelAI 이미지 연결 — 없어도 「그림 사용 안 함」으로 모두 쓸 수 있어요.

## 설치

루미버스의 확장 관리에서 이 저장소 주소로 설치하고, 권한을 승인해 주세요.

```
https://github.com/Ttealo/isekai_letters
```

| 권한 | 쓰는 곳 |
|---|---|
| `generation` | 답장·정리·상대 만들기 글 생성, 연결 목록 |
| `personas` | 페르소나 목록·이름·설명 |
| `characters` | 캐릭터 만들기·읽기, 초상화를 아바타로 |
| `world_books` | 상대 로어북 만들기·읽기·고치기 |
| `image_gen` | 그림 만들기, 이미지 연결·모델 목록 |
| `images` | WebP로 줄인 그림 올리기, 지운 상대의 그림 지우기 |
| `ui_panels` | 우체통 위젯과 편지첩 창 |
| `app_manipulation` | 편지첩을 화면 가득 열기(없으면 오른쪽에 붙이기) |
| `push_notification` | 편지 도착 알림 |

빠진 권한이 있으면 그 기능만 쉬고 나머지는 그대로 동작해요.

## 처음 시작하기

1. **우체통 확인** — 설치하면 화면에 작은 빨간 우체통이 떠 있고, 서랍에 **「이세계 편지」** 탭이 생겨요.
2. **글 연결 고르기** — `서랍 → 이세계 편지 → 설정 → 글`
   - 답장 쓰기 연결(비우면 기본 연결), 상대 만들기 연결
   - 막히면 대체 연결: 연결이 한도(429)에 걸리면 8초·20초 뒤 다시 해 보고, 그래도 안 되면 고른 연결로 넘겨요. 연결 설정에서 쓰던 연결을 하나 복사해 「대체용」으로 만들어 두면 든든해요.
3. **그림을 쓸지 정하기** — `설정 → 그림 → 그림 사용`. 쓰면 이미지 연결을 고르고, 안 쓰면 모습은 글로 받아요.
4. **초상화(선택)** — `설정 → 초상화`에서 NovelAI 연결을 고르고, 화풍·네거티브 프롬프트를 취향대로.
5. **상대 만나기** — `서랍 → 이세계 편지 → 새 상대` → 방식을 고르고 만들기 → 미리보기에서 카드·로어북·편지 재질·달력·시간 비율을 고친 뒤 확정.
6. **모습 갖추고 첫 편지** — 우체통 위젯을 누르면 편지첩이 열려요. 추억 상자 탭의 「모습」 카드에서 초상화·상징물·봉투·추억 상자를 그리고(또는 글로 받고), 서류함에서 「세계에 맞게 만들기」로 그 사람의 편지지를 만든 뒤, 편지첩 맨 아래에서 첫 편지를 써요.

## 설정 한눈에

| 탭 | 무엇을 |
|---|---|
| 글 | 답장·상대 만들기·정리 연결, 대체 연결, 답장 길이(최소·최대 글자), 묘사·기록부 문체, 내 편지 글씨체 |
| 그림 | 그림 사용, 이미지 연결·모델, 편지지 방식(꾸미기/그림), 받은 물건 자동 그리기, 하루·상대별 최대 장수, 종류별 연결·모델·양식 |
| 초상화 | NovelAI 연결·모델(V4.5·V5), 화풍·네거티브, 아바타로 쓰기, 요즘 모습으로 다시 그리기, 사진·그림류 동봉 |
| 편지 흐름 | 우체부가 늦을 확률, 남은 시간 분 단위, 먼저 오는 편지, 도착 알림·알림 시험 |
| 기억·기타 | 기억 예산, 백업 받기·되살리기, 편지첩 여는 방식(화면 가득·오른쪽·떠 있는 창) |

상대마다의 시간(시간 비율, 한 번 왕복 최대, 건너가는 데 · 받고 답장까지 · 건너오는 데 걸리는 시간, 먼저 쓰기까지)은 상대 화면의 **상대 정보 수정**에서 정해요. 예전에 만든 상대는 저장하기 전까지 예전 배송·답장 시간으로 돌아요. 숫자를 바꾸면 "내 하루 = 그쪽 3일"처럼 바로 풀어 보여 줘요.

## 무엇이 얼마나 드나요

| 일 | 드는 것 |
|---|---|
| 답장 한 통 | 글 1번 (정리를 켜면 1번 더) |
| 새 상대 · 편지지 테마 · 기록부 · 모습 글 · 사건 · 마무리 · 그 후 · 내 세계 초안 · 내 쪽 일 받기 | 누를 때마다 글 1번 |
| 시간 감기 | 그사이 내 쪽 일을 받으면 글 1번, 감은 사이 써지는 답장마다 글 1번 |
| 봉투 · 상징물 · 추억 상자 · 물건 그림 | 글 1번 + 그림 1장 |
| 초상화 · 그림 그려서 동봉 | 글 1번 + NovelAI 1장 |

연결이 한도에 걸려 대체 연결로 넘어갈 때는 처음 한 번 1분쯤 걸릴 수 있어요. 버튼 자리에 "…하는 중이에요"가 뜨면 기다려 주세요. 창을 닫아도 서버에서 계속돼요.

- 그림: 루미버스 이미지(브라우저에서 WebP로 줄여 다시 저장)

> 확장의 내부 식별자는 예전 이름 그대로 `isekai_mailbox`예요. 이름만 바뀌었고, 저장된 편지는 그대로 이어져요.

## 개발

```
node scripts/build.js      # src → dist (이어 붙이기, 의존성 없음)
npm test                   # 단위 + 가짜 호스트 통합 + 빌드 + 가짜 DOM 화면 점검
```

- `src/`: core(시간·편지·설정) · paper(편지지 테마) · match(상대 만들기) · memory(정리·기억) · art(그림 양식) · portrait(NovelAI 프롬프트) · report(기록부·모습 글) · story(사건·마무리) · myworld(내 세계·시간 감기) · exporthtml(HTML 저장) · backend · frontend
- 가짜 DOM 점검은 `linkedom`이 필요해요(상위 폴더의 node_modules를 빌려 씀).
- `dist/`는 설치 때 빌드 없이 쓰도록 저장소에 같이 올려요.
