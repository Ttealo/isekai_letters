# 이세계 우체통 (isekai_mailbox)

Lumiverse 확장. 내 페르소나가 다른 세계의 누군가와 **편지만** 주고받는다.
보낸 편지는 실제 시간으로 배송되고, 상대 쪽 시간은 다른 빠르기로 흐르며, 답장은 그동안 상대에게 생긴 일을 품고 돌아온다.

설계: [PLAN.md](PLAN.md)

## 현재 단계: 0.3.0

- **상대 자동 생성(매칭)**: 서랍 「새 상대」에서 네 방식
  - 원하는 상대 적기 → AI가 카드·세계·우편 설정으로 펼침
  - 무작위로 만나기(세계의 씨앗 주사위, 빼고 싶은 소재)
  - 기존 캐릭터(원본 카드·로어북은 그대로, 우편 설정과 「〈이름〉 · 우체통」 로어북만 새로)
  - 직접 다 적기(예전 양식)
  - 카드 양식은 CHARACTER_CARD_COMPACT(압축판). 시간 비율·배송·답장 시간·편지 매체·봉인·우표·냄새·감촉을 세계에 맞춰 정하고, 원하면 범위를 줌
  - 생성 1회 → 미리보기(모든 칸 수정, 항목 빼기·더하기, 경고 표시, 다시 만들기) → 확정해야 캐릭터·로어북·상대가 생김. 확정 중 실패하면 만든 것만 지움
  - 첫 편지: 상대가 먼저(낯선 편지) 또는 내가 먼저
- **답장에 로어북**: 상대 로어북(우체통 것 + 캐릭터에 붙은 것)에서 상시 항목과 최근 편지에 키워드가 나온 항목을 골라 넣음(약 6천 자 안). 편지 매체·봉인 등을 프롬프트에 고정
- 설정: 상대 만들기 연결·온도 따로

## 0.2.0까지

- **우체통 위젯**: 화면 위에 떠 있는 우체통(끌어서 이동). 새 편지가 오면 깃발이 올라가고 숫자가 붙는다. 누르면 보조창을 열고 닫는다(새 편지가 있으면 그 상대로 바로).
- **보조창**(오른쪽 도크, 크기 조절·접기, 모바일은 아래 시트): 맨 위 페르소나 → 그 페르소나의 상대 → 탭
  - 편지첩: 양쪽 편지를 편지지로(상대=누런 종이·명조체·우표 칸, 나=푸른 종이), 안 연 봉투는 감각 묘사 뒤 「봉투 열기」, 맨 아래 편지 쓰기
  - 물품: 받은 것 / 보낸 것 진열(그림 칸은 이미지 단계에서 채움)
  - 모음: 페르소나의 상대별 편지 묶음 + 모든 물건
- **서랍 탭**: 페르소나 칩으로 상대 거르기, 새 상대(페르소나 고르기)·수정, 편지 쓰기(보내는 사람·실제 배송 시간 표시), 설정
- **물품 장부**: 동봉물(한 줄에 하나, 최대 5개)을 따로 기록. 답장 프롬프트에 최근 오간 물품을 넣어 상대가 기억하게 함
- 시간: 상대별 비율·배송·답장 시간, 시험 가속. 프롬프트에서 그쪽 날짜·경과를 고정
- 실패 재시도, 재시작 복구, 계정별 분리(0.1.0과 같음). 0.1.0 저장본은 열 때 물품 장부를 자동으로 채움

아직 없음(다음 단계): 편지가 오가며 카드·로어북을 갱신하는 정리 단계, 달력, 먼저 오는 편지, 푸시 알림, 장기 기억 층, 이미지.

## 권한

- `generation` — 답장 생성, 연결 목록
- `personas` — 페르소나 목록·이름
- `ui_panels` — 우체통 위젯과 보조창(없으면 서랍 탭만으로 동작)
- `characters` — 매칭으로 캐릭터 만들기·기존 캐릭터 읽기
- `world_books` — 상대 로어북 만들기·읽기

## 개발

```
node scripts/build.js      # src → dist
npm test                   # 단위 + 가짜 호스트 통합 + 빌드 + 가짜 DOM 화면 점검
```

가짜 DOM 점검은 `../charge_P/node_modules/linkedom`을 빌려 쓴다.
dist는 저장소에 같이 올린다(설치 시 빌드 없이 바로 쓰도록).
