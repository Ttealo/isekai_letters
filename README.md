# 이세계 우체통 (isekai_mailbox)

Lumiverse 확장. 내 페르소나가 다른 세계의 누군가와 **편지만** 주고받는다.
보낸 편지는 실제 시간으로 배송되고, 상대 쪽 시간은 다른 빠르기로 흐르며, 답장은 그동안 상대에게 생긴 일을 품고 돌아온다.

설계: [PLAN.md](PLAN.md)

## 현재 단계: 0.9.0

- **편지지·우표 바뀜**: 설정에서 따로(사건이 있을 때(기본, 계절 변화 포함) / 그쪽 계절이 바뀔 때만 / 끄기). 정리 단계가 편지에서 사건(이사·계절·축제·물자 부족 등)을 찾거나 달력상 계절이 바뀌면 그 편지에 새 그림. 편지마다 자기 그림을 가져서 예전 편지는 예전 편지지·우표 그대로, 바뀐 편지엔 「✦ 새 우표 — 이유」
- **받은 물건 자동 그리기 기본 켬**(첫 편지 동봉물 포함). 그리기가 겹치면 거절하지 않고 앞의 것이 끝난 뒤 이어서
- **달력 탭**(0.8): 내 쪽 날짜 월 달력에 받은·보낸 편지, 날짜별 목록, 편지로 이동
- **그쪽 달력·먼저 오는 편지·푸시 알림**(0.7): 상대 세계 달력 표기, 답이 없으면 상대가 먼저 씀, 도착 알림·알림 시험

## 이전 단계

- **그림**: 상대마다 그림 세트(편지지·우표·봉인)와 물건마다 그림. 글 생성 1회로 그림 주제(영어)를 받고 이미지 연결(NanoGPT 등)로 그림. 사람·얼굴·손·글자 없음, 화풍은 설정에서
  - 편지첩: 상대 편지 뒤에 편지지 그림, 우표 칸에 우표, 안 연 봉투에 봉인. 머리에 「그림 세트 만들기」(빠진 것만)·「세트 다시 그리기」
  - 물품·모음: 그림 칸, 그림 없는 물건마다 「그리기」. 설정에서 받은 물건 자동 그리기
  - 하루 최대 장수(기본 6, 세트 포함). 모자라면 시작 전에 거절
  - WebP: 백엔드는 앱 이미지로 저장(png) → 우체통을 연 브라우저가 WebP(품질 0.85)로 바꿔 올리고 원본을 지움. 브라우저가 WebP를 못 만들면 3번 시도 후 png 유지

## 0.4.0까지

- **정리 단계**: 답장이 오면 한 번 더 생성(정리 연결·온도 따로, 끌 수 있음)해서
  - 편지마다 요약, 관계 장부(부르는 말·거리·마음·약속·안 받은 질문·기억할 날·상대가 아는 나·내가 아는 상대), 그쪽 연대기(진행 중/끝남), 10통마다 시기 요약
  - 로어북 추가·수정, 카드 칸 추가·수정 제안 → 잠근 칸은 제안만, 충돌은 표시만, 나머지는 적용 모드(자동/승인 후/끔)대로. 새로 만든 상대는 자동, 기존 캐릭터는 카드 승인 후·원본 로어북 끔
  - 모든 변경은 기록에 남고, 적용된 것은 되돌리기, 대기·잠김·실패는 적용/거절
  - 로어북이 없는 상대(직접 적은 상대)는 상대 안의 로컬 항목으로
- **장기 기억 층**: 관계 장부 / 최근 원문 / 편지 요약 / 시기 요약 / 그쪽 사건 / 로어북 / 옛 편지 회상(키워드) — 설정에서 층마다 예산
- **상대 서류함**(서랍 → 상대 → 서류함): 장부·연대기·시기 요약·편지 요약·변경 기록·규칙(잠금·적용 모드)·다음 답장 모의 조립(층별 글자·토큰·빠진 양, 실제 프롬프트 전체). 「아직 정리 안 된 편지 정리하기」로 예전 편지도 정리
- **보조창 방식**: 설정에서 오른쪽에 붙이기(밀어냄) / 떠 있는 창(겹침) — 기기별, 새로 고침 뒤 적용

## 0.3.0까지

- **상대 자동 생성(매칭)**: 서랍 「새 상대」에서 네 방식
  - 원하는 상대 적기 → AI가 카드·세계·우편 설정으로 펼침
  - 무작위로 만나기(세계의 씨앗 주사위, 빼고 싶은 소재)
  - 기존 캐릭터(원본 카드·로어북은 그대로, 우편 설정과 「〈이름〉 · 우체통」 로어북만 새로)
  - 직접 다 적기(예전 양식)
  - 카드 양식은 CHARACTER_CARD_COMPACT(압축판). 시간 비율·배송·답장 시간·편지 매체·봉인·우표·냄새·감촉을 세계에 맞춰 정하고, 원하면 범위를 줌
  - 생성 1회 → 미리보기(모든 칸 수정, 항목 빼기·더하기, 경고 표시, 다시 만들기) → 확정해야 캐릭터·로어북·상대가 생김. 확정 중 실패하면 만든 것만 지움
  - 첫 편지: 상대가 먼저(낯선 편지) 또는 내가 먼저
- **답장에 로어북**: 상대 로어북(우체통 것 + 캐릭터에 붙은 것)에서 상시 항목과 최근 편지에 키워드가 나온 항목을 골라 넣음(약 6천 자 안). 편지 매체·봉인 등을 프롬프트에 고정
- 설정: 상대 만들기 연결·온도 따로

## 0.2.0까지

- **우체통 위젯**: 화면 위에 떠 있는 우체통(끌어서 이동). 새 편지가 오면 깃발이 올라가고 숫자가 붙는다. 누르면 보조창을 열고 닫는다(새 편지가 있으면 그 상대로 바로).
- **보조창**(오른쪽 도크, 크기 조절·접기, 모바일은 아래 시트): 맨 위 페르소나 → 그 페르소나의 상대 → 탭
  - 편지첩: 양쪽 편지를 편지지로(상대=누런 종이·명조체·우표 칸, 나=푸른 종이), 안 연 봉투는 감각 묘사 뒤 「봉투 열기」, 맨 아래 편지 쓰기
  - 물품: 받은 것 / 보낸 것 진열(그림 칸은 이미지 단계에서 채움)
  - 모음: 페르소나의 상대별 편지 묶음 + 모든 물건
- **서랍 탭**: 페르소나 칩으로 상대 거르기, 새 상대(페르소나 고르기)·수정, 편지 쓰기(보내는 사람·실제 배송 시간 표시), 설정
- **물품 장부**: 동봉물(한 줄에 하나, 최대 5개)을 따로 기록. 답장 프롬프트에 최근 오간 물품을 넣어 상대가 기억하게 함
- 시간: 상대별 비율·배송·답장 시간, 시험 가속. 프롬프트에서 그쪽 날짜·경과를 고정
- 실패 재시도, 재시작 복구, 계정별 분리(0.1.0과 같음). 0.1.0 저장본은 열 때 물품 장부를 자동으로 채움

아직 없음(다음 단계): 달력, 먼저 오는 편지, 푸시 알림.

## 권한

- `generation` — 답장 생성, 연결 목록
- `personas` — 페르소나 목록·이름
- `ui_panels` — 우체통 위젯과 보조창(없으면 서랍 탭만으로 동작)
- `characters` — 매칭으로 캐릭터 만들기·기존 캐릭터 읽기
- `world_books` — 상대 로어북 만들기·읽기
- `image_gen` — 그림 만들기·이미지 연결 목록
- `images` — WebP로 바꾼 그림 올리기·원본 지우기
- `app_manipulation` — 편지첩을 채팅창처럼 화면 가득 열기(없으면 오른쪽에 붙이기)

## 개발

```
node scripts/build.js      # src → dist
npm test                   # 단위 + 가짜 호스트 통합 + 빌드 + 가짜 DOM 화면 점검
```

가짜 DOM 점검은 `../charge_P/node_modules/linkedom`을 빌려 쓴다.
dist는 저장소에 같이 올린다(설치 시 빌드 없이 바로 쓰도록).
