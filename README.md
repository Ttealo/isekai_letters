# 이세계 우체통 (isekai_mailbox)

Lumiverse 확장. 내 페르소나가 다른 세계의 누군가와 **편지만** 주고받는다.
보낸 편지는 실제 시간으로 배송되고, 상대 쪽 시간은 다른 빠르기로 흐르며, 답장은 그동안 상대에게 생긴 일을 품고 돌아온다.

설계: [PLAN.md](PLAN.md)

## 현재 단계: 1단계 (0.1.0)

- 서랍 탭 「우체통」: 우편함, 상대별 편지 묶음, 편지 쓰기·회수, 봉투 → 본문 열기, 상대 직접 입력·수정·삭제, 설정
- 시간: 상대별 시간 비율, 배송 시간 범위, 답장까지 걸리는 그쪽 시간, 답장까지 현실 최대 시간, 시험용 가속
- 답장: 1분마다 예약 검사 → 상대 쪽 사이 일지 + 봉투·동봉물 + 본문을 한 번의 생성으로 만든 뒤 배송
- 실패: 1분 → 5분 → 30분 재시도 후 「우편 사고」, 수동 다시 시도. 서버 재시작 시 생성 중이던 답장 재개
- 계정별 분리: 설치 범위가 operator여도 사용자마다 따로 저장·진행

아직 없음(다음 단계): 캐릭터 카드·로어북 자동 생성, 무작위 매칭, 달력, 먼저 오는 편지, 푸시 알림, 장기 기억 층, 이미지.

## 권한

- `generation` — 답장 생성, 연결 목록
- `personas` — 보낼 때의 내 페르소나 이름

## 개발

```
node scripts/build.js      # src → dist
npm test                   # 단위 + 가짜 호스트 통합 + 빌드 + 가짜 DOM 화면 점검
```

가짜 DOM 점검은 `../charge_P/node_modules/linkedom`을 빌려 쓴다.
dist는 저장소에 같이 올린다(설치 시 빌드 없이 바로 쓰도록).
